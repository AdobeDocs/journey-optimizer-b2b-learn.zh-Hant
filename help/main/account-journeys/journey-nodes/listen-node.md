# 接聽事件節點

使用[!DNL Adobe Journey Optimizer B2B Edition]中的[!UICONTROL 接聽事件]節點，在事件發生時推進歷程。 比較帳戶和人員事件、定義比對條件，並設定逾時以控制歷程等待的時間。

>[!VIDEO](https://video.tv.adobe.com/v/3443245/?captions=chi_hant&quality=12&learn=on)

## 接聽節點要點

影片涵蓋下列主題：

* 帳戶事件和個人事件之間的差異。
* 符合事件觸發器的條件。
* 未在指定時間內發生的事件逾時設定。

## 相關文件

如需支援的事件、設定步驟和逾時選項，請參閱使用手冊[&#128279;](https://experienceleague.adobe.com/zh-hant/docs/journey-optimizer-b2b/user/journeys/journey-nodes/listen-for-event-nodes){target="_blank"}中的接聽事件。

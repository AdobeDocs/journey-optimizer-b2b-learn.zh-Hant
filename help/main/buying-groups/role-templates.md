# 購買群組角色範本

瞭解如何在[!DNL Adobe Journey Optimizer B2B Edition]中建立角色範本。 這些範本定義誰參與購買決定、如何將人員指派給角色，以及讓購買群組完成的原因。 本影片涵蓋範本建立、角色設定和發佈。

此教學課程適用於使用[!DNL Journey Optimizer B2B Edition]進行帳戶式行銷，且想要鎖定每個帳戶中適當利害關係人的行銷人員和管理員。

>[!VIDEO](https://video.tv.adobe.com/v/3453312/?captions=chi_hant&learn=on)

了解做法：

* 開啟「購買」群組下的「角色範本」詳細目錄，並將草稿範本與即時範本區分開來。
* 以唯一名稱和說明建立新角色範本。
* 設定角色，包括其權重、自動指派和完整度要求。
* 定義每個角色的指派條件，例如符合職稱。
* 若要包含所有參與者，請新增更多角色，例如「決策者」、「從業者」和「影響者」。
* 設定角色優先順序，以便將人員指派給符合條件的第一個角色。
* 使用完整度分數設定來設定每個角色所需的成員數目。
* 發佈範本，使其狀態變更為「即時」，以供解決方案興趣使用。

如需詳細資訊，請參閱使用手冊中的[購買群組角色範本](https://experienceleague.adobe.com/zh-hant/docs/journey-optimizer-b2b/user/accounts/buying-groups/buying-groups-role-templates)。
